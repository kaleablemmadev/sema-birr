# Welcome to SemaBirr

## Problem Statement
With the rise of digital transactions, especially after the introduction of Telebirr, many simple transactions like that in small shops and even in transporations (minibus/taxi) are being made using those mechanisms. This brought a major coordination issue; shop owners and taxis collect both digital payments and cash payments simultaneously, which proved hard to handle efficiently while driving or in a crowded shop space.

## Features
- Speaks a received transaction in short terms for user to hear
- Turn on/off feature for specific time uses
- Daily, Weekly and Monthly Trasaction Logs
